    4. Handle AppMsg::CharactersOutput in update():
       - `CharactersPanelOutput::SaveCharacter(character)` → `self.db_worker.sender().send(DbInput::SaveCharacter(character))`
       - `CharactersPanelOutput::DeleteCharacter(id)`:
         - Send DbInput::DeleteCharacter(id)
         - Delete avatar file from data directory on background thread
       - `CharactersPanelOutput::EditCharacter(id)`:
         - If id is empty → launch CharacterEditor with CharacterEditorInit::New
         - If id is non-empty → find character in loaded list, launch CharacterEditor with CharacterEditorInit::Edit(character)
         - Store editor controller in model.character_editor
       - `CharactersPanelOutput::RequestImport`:
         - Create GtkFileChooserNative with filter for .png and .json files
         - Store file chooser in model to keep alive
         - On response: read file, call card_io::import_from_png or card_io::import_from_json on background thread
         - On success: save character to DB, reload characters list
         - On error: show toast with error message
       - `CharactersPanelOutput::RequestExport(id)`:
         - Find character in loaded list
         - Create GtkFileChooserNative with suggestion "{slugified_name}.png"
         - On response: call card_io::export_to_png or export_to_json on background thread
         - Write result to chosen file path

    5. Handle AppMsg::EditorOutput in update():
       - `CharacterEditorOutput::Saved(character)`:
         - Save character to DB via DbInput::SaveCharacter
         - Reload characters list
         - Close editor (set model.character_editor = None)
         - Show toast "Character saved"
       - `CharacterEditorOutput::Cancelled`:
         - Close editor (set model.character_editor = None)

    6. Handle DbOutput character variants in AppMsg::DbResult:
       - `DbOutput::CharactersLoaded(chars)` → forward to CharactersPanel
       - `DbOutput::CharacterSaved(_)` → reload characters list
       - `DbOutput::CharacterDeleted(_)` → reload characters list
