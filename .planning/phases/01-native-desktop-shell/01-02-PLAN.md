# Plan 01-02: Configure Tauri v2 Capabilities and Permissions

**Goal:** Create all 7 Tauri v2 capability files with the correct permissions for Phase 1. This is the security layer that gates what the webview can do — core window operations, and stub permissions for future plugin features.

---

<threat_model>

| Threat ID | Threat | Severity | Mitigation | Phase 1 Status |
|-----------|--------|----------|------------|-----------------|
| T-2-01 | Unauthorized IPC commands from webview | Medium | Capability system restricts which commands the webview can invoke | Per-feature capability files with minimal permissions |
| T-2-02 | Overly permissive capability grants | Medium | Per-feature scoping — each domain only gets `default` permissions in Phase 1 | Stub files use `*:default` only |
| T-2-03 | WebView escape via filesystem access | Medium | `filesystem.json` only grants `fs:default` — no app data dir access yet | No sensitive scopes defined |

</threat_model>

---

## Task 01-02-01: Configure default.json capability with core permissions

<read_first>
- persona/src-tauri/capabilities/default.json (created by tauri init)
- persona/src-tauri/tauri.conf.json (verify identifier matches)
</read_first>

<action>
Replace the content of `src-tauri/capabilities/default.json` with:

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "default",
  "description": "Core permissions for the main Revelry window",
  "windows": ["main"],
  "permissions": [
    "core:path:default",
    "core:event:default",
    "core:window:default",
    "core:app:default",
    "core:resources:default",
    "core:menu:default",
    "core:tray:default"
  ]
}
```

This replaces the tauri init scaffold with the explicit core permissions list per D-12.
</action>

<acceptance_criteria>
- `src-tauri/capabilities/default.json` contains `"identifier": "default"`
- `src-tauri/capabilities/default.json` contains `"windows": ["main"]`
- `src-tauri/capabilities/default.json` contains `"core:path:default"`
- `src-tauri/capabilities/default.json` contains `"core:window:default"`
- `src-tauri/capabilities/default.json` contains `"core:event:default"`
- `src-tauri/capabilities/default.json` contains exactly 7 entries in `"permissions"` array
</acceptance_criteria>

## Task 01-02-02: Create window.json capability

<read_first>
- persona/src-tauri/capabilities/default.json (for schema reference)
</read_first>

<action>
Create new file `src-tauri/capabilities/window.json` with:

```json

  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "window",
  "description": "Window management permissions",
  "windows": ["main"],
  "permissions": [
    "core:window:allow-set-title",
    "core:window:allow-close",
    "core:window:allow-set-size",
    "core:window:allow-set-position",
    "core:window:allow-set-fullscreen",
    "core:window:allow-minimize",
    "core:window:allow-maximize",
    "core:window:allow-unminimize",
    "core:window:allow-unmaximize",
    "core:window:allow-is-maximized",
    "core:window:allow-is-minimized",
    "core:window:allow-is-fullscreen",
    "core:window:allow-start-dragging",
    "core:window:allow-toggle-maximize"
  ]
}
```

These permissions enable the AppHeader drag region (via `start-dragging`) and window controls needed for the native desktop experience.
