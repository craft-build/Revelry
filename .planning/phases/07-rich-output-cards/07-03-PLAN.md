# Plan 07-03: Shiki Preloading + Markdown Polish

Add Shiki engine preloading to `+layout.svelte` so code blocks render instantly on first AI response. This is a small single-task plan that depends on 07-01 (MarkdownRenderer must exist).

## Task 1: Preload Shiki in root layout

<read_first>

- src/routes/+layout.svelte (the root layout with `onMount` and `$effect` hooks)
- src/lib/components/chat/MarkdownRenderer.svelte (created by 07-01 — has `createHighlighter` import)
  </read_first>

<action>
In `src/routes/+layout.svelte`, add Shiki preloading inside the existing `onMount` callback. This ensures the Shiki WASM engine and common language grammars are loaded early, before any chat messages are rendered.

Add this import at the top of the script block:

```typescript
import { createHighlighter } from "shiki";
```

Add this code inside the `onMount(() => { ... })` callback, after the `window.addEventListener('keydown', onkey);` line and before the cleanup return:

```typescript
// Preload Shiki syntax highlighting engine (used by MarkdownRenderer)
createHighlighter({
  themes: ["vitesse-dark"],
  langs: [
    "javascript",
    "typescript",
    "python",
    "rust",
    "json",
    "html",
    "css",
    "bash",
    "markdown",
  ],
})
  .then(() => {
    // Shiki engine cached internally — MarkdownRenderer will reuse it
  })
  .catch((err: unknown) => {
    console.warn("Shiki preload failed (non-critical):", err);
  });
```

Do NOT `await` this — it should be fire-and-forget so it doesn't block app startup. The `MarkdownRenderer` component will handle its own `createHighlighter` call if preloading hasn't finished yet.
</action>
