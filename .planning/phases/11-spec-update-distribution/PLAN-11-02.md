<action>
Create `.gitlab-ci.yml` at the project root with the following pipeline:

```yaml
stages:
  - build
  - release

variables:
  CARGO_HOME: $CI_PROJECT_DIR/.cargo
  RUST_BACKTRACE: "1"

# -------------------------------------------------------------------
# Linux AppImage Build
# -------------------------------------------------------------------
build:linux:
  stage: build
  image: ubuntu:22.04
  before_script:
    - apt-get update && apt-get install -y
      curl
      build-essential
      pkg-config
      libssl-dev
      libwebkit2gtk-4.1-dev
      libgtk-3-dev
      libayatana-appindicator3-dev
      librsvg2-dev
      file
    - curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
    - source "$HOME/.cargo/env"
    - curl -fsSL https://bun.sh/install | bash
    - export PATH="$HOME/.bun/bin:$PATH"
    - bun install
  script:
    - source "$HOME/.cargo/env"
    - bunx tauri build --bundles appimage
    - echo "LINUX_JOB_ID=$CI_JOB_ID" > build.env
  artifacts:
    paths:
      - src-tauri/target/release/bundle/appimage/*.AppImage
    reports:
      dotenv: build.env
    expire_in: 30 days
  cache:
    key:
      files:
        - Cargo.lock
      prefix: linux
    paths:
      - .cargo/registry/
      - .cargo/git/
      - src-tauri/target/
  rules:
    - if: $CI_COMMIT_TAG =~ /^v\d+\.\d+\.\d+$/
    - when: manual

# -------------------------------------------------------------------
# Windows NSIS Build
# -------------------------------------------------------------------
build:windows:
  stage: build
  tags:
    - shared-windows
    - windows
    - windows-1809
  before_script:
    - choco install rustup.install -y
    - $env:Path = [System.Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [System.Environment]::GetEnvironmentVariable('Path','User')
    - rustup default stable
    - rustup target add x86_64-pc-windows-msvc
    - powershell -Command "irm bun.sh/install.ps1 | iex"
    - $env:Path = "$env:USERPROFILE\.bun\bin;$env:Path"
    - bun install
  script:
    - $env:Path = [System.Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [System.Environment]::GetEnvironmentVariable('Path','User')
    - bunx tauri build --bundles nsis
    - echo "WINDOWS_JOB_ID=$CI_JOB_ID" > build.env
  artifacts:
    paths:
      - src-tauri/target/release/bundle/nsis/*.exe
    reports:
      dotenv: build.env
    expire_in: 30 days
  cache:
    key:
      files:
        - Cargo.lock
      prefix: windows
    paths:
      - .cargo/registry/
      - .cargo/git/
      - src-tauri/target/
  rules:
    - if: $CI_COMMIT_TAG =~ /^v\d+\.\d+\.\d+$/
    - when: manual

# -------------------------------------------------------------------
# Release — Upload all artifacts to GitLab Release
# -------------------------------------------------------------------
release:
  stage: release
  image: registry.gitlab.com/gitlab-org/release-cli:latest
  needs:
    - job: build:linux
      artifacts: true
    - job: build:windows
      artifacts: true
  script:
    - echo "Creating release for $CI_COMMIT_TAG"
  release:
    tag_name: $CI_COMMIT_TAG
    name: "Revelry $CI_COMMIT_TAG"
    description: |
      Revelry AI Roleplay Desktop App — $CI_COMMIT_TAG

      ## Downloads
      - **Linux:** Download the `.AppImage` file, make executable (`chmod +x`), and run
      - **Windows:** Download the `.exe` installer and run
      - **macOS:** Not available via CI — build locally with `bunx tauri build`

      ## First Launch
      - **macOS:** Right-click the app → Open (required for unsigned apps)
      - **Windows:** Click "More info" → "Run anyway" if SmartScreen appears
      - **Linux:** `chmod +x Revelry_*.AppImage && ./Revelry_*.AppImage`
    assets:
      links:
        - name: "Linux AppImage"
          url: "${CI_PROJECT_URL}/-/jobs/${LINUX_JOB_ID}/artifacts/file/src-tauri/target/release/bundle/appimage/Revelry_${CI_COMMIT_TAG#v}_amd64.AppImage"
          filepath: "/revelry-linux.AppImage"
          link_type: package
        - name: "Windows Installer"
          url: "${CI_PROJECT_URL}/-/jobs/${WINDOWS_JOB_ID}/artifacts/file/src-tauri/target/release/bundle/nsis/Revelry_${CI_COMMIT_TAG#v}_x64-setup.exe"
          filepath: "/revelry-windows-setup.exe"
          link_type: package
  rules:
    - if: $CI_COMMIT_TAG =~ /^v\d+\.\d+\.\d+$/
      when: on_success
```

Notes on the pipeline:

- Linux build uses `ubuntu:22.04` Docker image with all required `-dev` packages
- Windows build uses GitLab shared Windows runner (`windows-1809` tag)
- `refreshenv` is NOT available on GitLab Windows runners — instead, PATH is refreshed inline via `[System.Environment]::GetEnvironmentVariable('Path','Machine')`
- Both builds use `bunx tauri build` (not `bun run tauri`) because `bun run` interprets `tauri` as a package.json script name
- Both builds emit a dotenv artifact (`build.env`) containing `$CI_JOB_ID` so the release job can reference build artifacts by their actual job IDs
- Release asset filenames use `${CI_COMMIT_TAG#v}` to derive the version dynamically from the tag (e.g., `v0.2.0` → `0.2.0`) — no hardcoded version strings
- Both builds cache `$CARGO_HOME` and `target/` keyed by `Cargo.lock` hash for incremental builds
- Both builds trigger on semantic version tags (`v*.*.*`) OR manual trigger
- Release job creates a GitLab Release with download links and first-launch instructions
- macOS build is NOT in CI — built locally per D-04

````markdown
# Build and Distribution

## Prerequisites

### macOS

- Xcode Command Line Tools: `xcode-select --install`
- Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
- Bun: `curl -fsSL https://bun.sh/install | bash`

### Linux (Ubuntu/Debian)

- System dependencies:
  ```bash
  sudo apt install build-essential pkg-config libssl-dev \
    libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev \
    librsvg2-dev file
  ```
````

- Rust and Bun (same as macOS)

### Windows

- Visual Studio Build Tools 2022 (with C++ build tools workload)
- WebView2 (bundled by Tauri; pre-installed on Windows 11)
- Rust: `winget install Rustlang.Rustup`
- Bun: `powershell -c "irm bun.sh/install.ps1 | iex"`

## Building Locally

```bash
# Install frontend dependencies
bun install

# Development mode
bun run tauri:dev

# Production build (platform-native output)
bun run tauri:build
```

Build outputs:

- **macOS:** `src-tauri/target/release/bundle/dmg/Revelry_0.1.0_x64.dmg`
- **Linux:** `src-tauri/target/release/bundle/appimage/Revelry_0.1.0_amd64.AppImage`
- **Windows:** `src-tauri/target/release/bundle/nsis/Revelry_0.1.0_x64-setup.exe`

## CI/CD Pipeline

Builds for Linux (AppImage) and Windows (NSIS) run on GitLab CI when a `v*.*.*` tag is pushed. macOS DMG is built locally.

### Triggering a Release

```bash
git tag v0.1.0
git push origin v0.1.0
```

This triggers:

1. Linux AppImage build (Ubuntu Docker executor)
2. Windows NSIS build (Windows shared runner)
3. GitLab Release creation with download links

Upload the macOS DMG manually to the GitLab Release after building locally.

### Manual Build Trigger

Navigate to CI/CD → Pipelines in GitLab and click "Run pipeline" for manual builds.

## Distribution Notes

### Code Signing (Not Implemented in v1)

This release is unsigned. Users will see OS warnings on first launch:

- **macOS:** Right-click the app → Open → Open (bypasses Gatekeeper)
  Alternatively: System Preferences → Privacy & Security → Open Anyway
- **Windows:** Click "More info" → "Run anyway" to bypass SmartScreen
- **Linux:** `chmod +x Revelry_*.AppImage && ./Revelry_*.AppImage`

### Platform Notes

- **SQLite:** Statically compiled via rusqlite `bundled` feature — no external dependency
- **WebView:** Tauri uses the system WebView (WebKit on macOS/Linux, WebView2 on Windows)
- **Icons:** All icon formats (PNG, ICO, ICNS) bundled in `src-tauri/icons/`
