  <action>
    **Add edit state:**
    - `isEditing = $state<boolean>(false)`
    - `editContent = $state<string>('')` — holds the textarea value during edit
    - `isSaving = $state<boolean>(false)` — true while editResend is in progress

    **Enter edit mode:** When the Edit (Pencil) button is clicked on a user message:
    - Set `editContent = message.content`
    - Set `isEditing = true`

    **Edit mode rendering:** When `isEditing` is true:
    - Replace the bubble `<p>` content area with a `<textarea>`:
      - `class="w-full resize-none bg-(--color-surface-input) text-[14px] leading-relaxed text-(--color-foreground) p-3 rounded-(--radius-md) border border-(--color-border) focus:border-(--color-accent) focus:outline-none"`
      - `bind:value={editContent}`
      - Auto-grow behavior (same as MessageInput — oninput, set height to auto then min of scrollHeight and 240px)
      - `disabled={isSaving}`
    - Replace the normal hover actions row with edit action buttons:
      - "Save & resend" button: `class="inline-flex items-center gap-1.5 rounded-(--radius-sm) bg-(--color-accent) px-3 py-1 text-xs font-medium text-(--color-accent-fg) hover:bg-(--color-accent)/90 disabled:opacity-50"` — onclick calls `handleSaveResend()`. When isSaving: show `Loader2` icon with `class="size-3 animate-spin"`, label changes to "Saving…", button disabled.
      - "Discard changes" button: `class="inline-flex items-center gap-1.5 rounded-(--radius-sm) px-3 py-1 text-xs font-medium text-(--color-subtle) hover:text-(--color-foreground) disabled:opacity-50"` — onclick calls `handleCancelEdit()`. When isSaving: button disabled.

    **handleSaveResend function:**
    - If `editContent.trim()` is empty, return (don't send empty messages)
    - If `editContent === message.content`, cancel edit (no change)
    - Set `isSaving = true`
    - Call `await app.editResend(message.id, editContent.trim())`
    - On success or failure, set `isEditing = false` and `isSaving = false` (the app.editResend handles the state changes; the edit mode exits when saving starts)

    **handleCancelEdit function:**
    - Set `isEditing = false`
    - Reset `editContent = ''`

    **Keyboard shortcuts in edit mode:**
    - Add `onkeydown` handler to the textarea:
      - Escape: call `handleCancelEdit()` (if not saving)
      - Ctrl/Cmd+Enter: call `handleSaveResend()` (if not saving)
    - Use `e.preventDefault()` for handled keys

    **Edit button visibility:** Already handled in Plan 04 — Edit only shows on user messages. Make sure the Edit button onclick calls the edit mode enter function.

    **No confirmation dialog:** Per D-08 and UI-SPEC, "Save & resend" immediately triggers truncation without a "This will delete N messages" confirmation.
