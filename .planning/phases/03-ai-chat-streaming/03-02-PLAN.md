<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → ChatPanel | Text messages may contain any Unicode content, submitted to external AI providers |
| AI response → MessageRow | Untrusted AI content rendered as Pango markup — must be escaped |
| Keyring → AppModel → ChatPanel | API key loaded from OS keychain, passed to rig client in command closure |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | S (Spoofing) | message_row.rs | mitigate | Pango entity escaping in MessageRow — assistant messages rendered via markdown_to_pango (already escapes), user messages escaped separately |
| T-03-08 | T (Tampering) | input_bar.rs | accept | User controls input content — no cross-user risk |
| T-03-09 | I (Info Disclosure) | app.rs | mitigate | API key loaded from keyring in spawn_oneshot_command, passed directly to command closure, never stored in model or logged |
| T-03-10 | D (Denial of Service) | chat/mod.rs | mitigate | Streaming command uses ShutdownReceiver for cancellation. No way to spawn multiple concurrent streams (streaming flag prevents double-send) |
| T-03-11 | E (Elevation) | N/A | accept | No privilege boundaries in single-process desktop app |
</threat_model>
