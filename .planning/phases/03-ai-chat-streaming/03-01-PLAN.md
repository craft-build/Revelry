The command closure receives a `ShutdownReceiver`; if the component is dropped, the shutdown receiver fires and `drop_on_shutdown()` cancels the future.        FINAL DESIGN: AiService provides one public async function:
       ```rust
       pub async fn stream_chat(
           provider: ProviderConfig,
           api_key: String,
           system_prompt: String,
           user_message: String,
           chat_history: Vec<rig::message::Message>,
       ```

       Where `StreamedResponse` contains a `futures::Stream` of tokens. But streams can't easily be type-erased either.

       PRACTICAL SOLUTION: AiService is a helper module with a macro or match-based function. The ChatPanel will call a command that:
       1. Loads the API key from keyring
       2. Calls `AiService::stream_with_provider(provider, api_key, preamble, message, history, &sender)` which handles provider dispatch internally and sends StreamChunk values through a provided mpsc sender.
       
       Use `tokio::sync::mpsc::Sender<StreamChunk>` as the output channel:
       ```rust
       pub async fn stream_with_provider(
           provider: ProviderConfig,
           api_key: String,
           preamble: String,
           user_message: String,
           chat_history: Vec<rig::message::Message>,
           output: tokio::sync::mpsc::Sender<StreamChunk>,
       ) {
           match provider.provider_type {
               ProviderType::OpenAI => {
                   let client = rig::providers::openai::Client::new(&api_key);
                   let agent = client.agent(&provider.model_name)
                       .preamble(&preamble)
                       .temperature(provider.temperature.unwrap_or(0.8))
                       .build();
                   let mut stream = agent.stream_chat(user_message, chat_history).await
                       .map_err(|e| output.send(StreamChunk::Error(e.to_string())))?;
                   while let Some(chunk) = stream.next().await {
                       match chunk {
                           Ok(MultiTurnStreamItem::StreamAssistantItem(StreamedAssistantContent::Text(text))) => {
                               output.send(StreamChunk::Token(text.text)).await.ok();
                           }
                           Ok(MultiTurnStreamItem::FinalResponse(resp)) => {
                               output.send(StreamChunk::Complete(resp.response().to_string())).await.ok();
                           }
                           Err(e) => { output.send(StreamChunk::Error(e.to_string())).await.ok(); break; }
                           _ => {}
                       }
                   }
               }
               // ... other providers
           }
       }
       ```
