# Plan 06-03: Wire Token Count Display to Real Backend Data

Update the frontend to consume real budget info from the extended `StreamChunk::Complete` event. Replace the hardcoded 8192 context limit and `estimateTokens()` heuristic with data from AppState's new `context_budget` field. Implement the three-tier color shift (green/yellow/red) on the context bar.

## Task 1: Extend StreamChunk type and add ContextBudget interface

<read_first>

- src/lib/types/index.ts (StreamChunk type, current complete variant has messageId, content, stopReason)
  </read_first>

<action>
In `src/lib/types/index.ts`, make two changes:

### 1a. Extend StreamChunk complete variant

**Current:**

```typescript
export type StreamChunk =
  | { event: "token"; data: { content: string } }
  | {
      event: "complete";
      data: { messageId: string; content: string; stopReason: string };
    }
  | { event: "error"; data: { error: string; errorType: string } };
```

**Change to:**

```typescript
export type StreamChunk =
  | { event: "token"; data: { content: string } }
  | {
      event: "complete";
      data: {
        messageId: string;
        content: string;
        stopReason: string;
        tokensUsed: number;
        tokensLimit: number;
        truncatedCount: number;
      };
    }
  | { event: "error"; data: { error: string; errorType: string } };
```

### 1b. Add ContextBudget interface

Add after the `StreamChunk` type (before the `Conversation` interface):

```typescript
/** Context budget info returned from backend after each generation. */
export interface ContextBudget {
  tokensUsed: number;
  tokensLimit: number;
  truncatedCount: number;
}
```

Do NOT remove the `estimateTokens()` function in `src/lib/utils/index.ts` — it may be used elsewhere and is explicitly kept per UI-SPEC decision #3.
</action>

<acceptance_criteria>

- `src/lib/types/index.ts` StreamChunk complete variant has `tokensUsed: number`, `tokensLimit: number`, `truncatedCount: number` fields
- `src/lib/types/index.ts` contains `export interface ContextBudget` with fields `tokensUsed`, `tokensLimit`, `truncatedCount`
- `estimateTokens()` in `src/lib/utils/index.ts` is NOT removed (file is not modified)
  </acceptance_criteria>

## Task 3: Replace MessageInput context bar with real backend data and color coding

<read_first>

- src/lib/components/chat/MessageInput.svelte (current context bar uses estimateTokens + hardcoded 8192)
- src/app.css (theme tokens: --color-success, --color-warning, --color-destructive, --color-surface-elevated)
  </read_first>

<action>
In `src/lib/components/chat/MessageInput.svelte`, make these changes:

### 3a. Remove estimateTokens import and derived values

**Remove** the import:

```typescript
import { estimateTokens } from "$lib/utils";
```

**Remove** these derived values:

```typescript
let tokens = $derived(estimateTokens(text));
let usedContext = $derived(
  app.messages.reduce(
    (sum, m) => sum + (m.token_count ?? estimateTokens(m.content)),
    0,
  ) + tokens,
);
const contextLimit = 8192;
let contextPct = $derived(Math.min(100, (usedContext / contextLimit) * 100));
```

**Replace with:**

```typescript
let usedContext = $derived(app.context_budget?.tokensUsed ?? 0);
let contextLimit = $derived(app.context_budget?.tokensLimit ?? 8192);
let contextPct = $derived(
  contextLimit > 0 ? Math.min(100, (usedContext / contextLimit) * 100) : 0,
);

/** Returns the semantic color token for the progress bar fill based on utilization. */
let barColor = $derived.by(() => {
  if (contextPct > 95) return "bg-(--color-destructive)";
  if (contextPct >= 80) return "bg-(--color-warning)";
  return "bg-(--color-success)";
});
```

### 3b. Update the context bar HTML

Replace the existing context bar div:

```html
<div
  class="mb-2 flex items-center justify-between gap-3 px-1 text-[10px] uppercase tracking-wider text-(--color-subtle)"
>
  <div class="flex items-center gap-2">
    <span
      >{usedContext.toLocaleString()} / {contextLimit.toLocaleString()}
      tok</span
    >
    <div
      class="h-1 w-32 overflow-hidden rounded-full bg-(--color-surface-elevated)"
    >
      <div
        class="h-full bg-(--color-accent) transition-[width] duration-300"
        style:width="{contextPct}%"
      ></div>
    </div>
  </div>
  <div class="flex items-center gap-2">
    <span>Enter to send · Shift+Enter for newline</span>
  </div>
</div>
```

**With:**

```html
<div
  class="mb-2 flex items-center justify-between gap-3 px-1 text-[10px] uppercase tracking-wider text-(--color-subtle)"
>
  <div class="flex items-center gap-2">
    <span
      >{usedContext.toLocaleString()} / {contextLimit.toLocaleString()}
      tok</span
    >
    <div
      class="h-1 w-32 overflow-hidden rounded-full bg-(--color-surface-elevated)"
    >
      <div
        class="h-full {barColor} transition-[width,background-color] duration-300"
        style:width="{contextPct}%"
      ></div>
    </div>
  </div>
  <div class="flex items-center gap-2">
    <span>Enter to send · Shift+Enter for newline</span>
  </div>
</div>
```

Key changes:

- `bg-(--color-accent)` replaced with `{barColor}` (dynamic class from `$derived`)
- `transition-[width]` replaced with `transition-[width,background-color]` to smooth color shifts
- All other attributes remain identical
  </action>
