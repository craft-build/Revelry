1. **start_conversation(conn, character_id):** This is the most complex function. It must:
   a. Load the character by `character_id` using `characters::load_character()`
   b. If character not found, return error
   c. Create a `Conversation::new(character_id)` and set:
   - `title = format!("Chat with {}", character.name)` (D-13)
   - `last_message_preview = character.first_mes.clone()` (D-13)
     d. INSERT the conversation with ALL columns including title and last_message_preview
     e. If character has a non-empty `first_mes`, create a `Message::new()` with role=Assistant, content=first_mes, sort_order=0, and insert it via `save_message()`
     f. Return the created Conversation

2. **load_conversations(conn):** SELECT all columns including title, last_message_preview, generation_preset_id ORDER BY updated_at DESC. Use `row_to_conversation` mapper.

3. **delete_conversation(conn, id):** DELETE WHERE id = ?1. CASCADE will handle messages.

4. **load_messages(conn, conversation_id):** SELECT id, conversation_id, role, content, sort_order, timestamp FROM messages WHERE conversation_id = ?1 ORDER BY sort_order ASC. Use `row_to_message` mapper. NO branch_id filtering.

5. **save_message(conn, msg):** INSERT the message, then UPDATE the conversation's `updated_at` and `last_message_preview`:

   ```sql
   UPDATE conversations SET updated_at = ?1, last_message_preview = ?2 WHERE id = ?3
   ```

   Where `?2` is the message content truncated to 100 chars: `msg.content.chars().take(100).collect::<String>()`
   Timestamps use `Utc::now().to_rfc3339()`.

6. **search_conversations(conn, query):** SQL LIKE search on title and last_message_preview (CONV-03). Pattern: `WHERE title LIKE '%' || ?1 || '%' OR last_message_preview LIKE '%' || ?1 || '%'`. Return empty Vec for empty queries. Use `row_to_conversation` mapper.

7. **update_conversation_persona(conn, conversation_id, persona_id):** Updates the conversation's creator_persona_id to persist persona switcher changes (PERS-05). Pattern: `UPDATE conversations SET creator_persona_id = ?1, updated_at = ?2 WHERE id = ?3`. The `updated_at` is set to `Utc::now().to_rfc3339()`. If `persona_id` is `None`, sets `creator_persona_id = NULL` (user cleared the persona). Return `Result<()>`.

Do NOT port: `load_branches_for_message`, `create_branch`, `count_messages_in_conversation`, `update_conversation_preset`, `update_message_content`, `delete_message` — these are Phase 7/8 concerns.
