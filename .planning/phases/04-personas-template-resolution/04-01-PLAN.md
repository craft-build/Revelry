       ```rust
       /// Resolves template variables in a string using the provided persona and character.
       /// Supported variables:
       /// - {{user}} → persona.name (or "User" if no persona per D-08)
       /// - {{char}} → character.name
       /// - {{persona.name}} → persona.name
       /// - {{persona.appearance}} → persona.appearance
       /// - {{persona.personality}} → persona.personality
       /// - {{persona.background}} → persona.background
       /// - {{persona.role_description}} → persona.role_description
       /// - {{persona.relationships}} → persona.relationships
       /// - {{persona.speech_style}} → persona.speech_style
       /// Unknown variables are left untouched (no replacement occurs).
       /// Variables referencing empty fields resolve to empty strings (D-06).
       pub fn resolve_variables(
           text: &str,
           persona: Option<&Persona>,
           character: &CharacterCardV2,
       ) -> String
       ```
       
       Implementation approach (per D-06: "simple string replacement"):
       - Use two-pass regex replacement OR simple string replacement
       - First resolve {{user}} and {{char}} (these might appear inside longer strings)
       - Then resolve {{persona.*}} variables
       - Use a HashMap for persona field mapping internally
       - Leave unknown {{...}} untouched
       - Order matters: resolve persona-specific ones first, then {{user}}/{{char}}, to avoid nested issues
