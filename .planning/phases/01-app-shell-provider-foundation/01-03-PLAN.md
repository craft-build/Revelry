     ```rust
     use anyhow::Result;
     use keyring::Entry;

     pub struct KeyringStore;

     impl KeyringStore {
         const SERVICE_NAME: &'static str = "revelry";

         pub fn save_key(provider_id: &str, api_key: &str) -> Result<()> {
             let entry = Entry::new(Self::SERVICE_NAME, provider_id)?;
             entry.set_password(api_key)?;
             Ok(())
         }

         pub fn load_key(provider_id: &str) -> Result<String> {
             let entry = Entry::new(Self::SERVICE_NAME, provider_id)?;
             let password = entry.get_password()?;
             Ok(password)
         }

         pub fn delete_key(provider_id: &str) -> Result<()> {
             let entry = Entry::new(Self::SERVICE_NAME, provider_id)?;
             entry.delete_credential()?;
             Ok(())
         }
     }
     ```
     Note: keyring operations are synchronous and must run on a background thread (spawn_oneshot_command).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application ↔ OS Keychain | API keys stored in OS credential store. Keychain may be unavailable. |
| Application ↔ AI Provider APIs | Outbound HTTPS connections to AI provider endpoints. API keys sent as authentication. |
| Application ↔ SQLite | Provider metadata in local database. No API keys in database. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | providers table | mitigate | No api_key column — verified by D-16 and unit test |
| T-01-06 | Information Disclosure | KeyringStore | mitigate | API keys stored exclusively in OS keychain via keyring crate. Never logged, never in DB. |
| T-01-07 | Denial of Service | Provider test | accept | 10-second timeout prevents hanging. Provider test failure is user-visible (spinner -> error icon). |
| T-01-08 | Spoofing | AI provider connection | accept | TLS enforced by rig/reqwest for all cloud providers. Local providers (Ollama) on localhost. |
| T-01-09 | Information Disclosure | Tracing/logging | mitigate | Never log API keys. Use tracing with env-filter. Redact keys in error messages. Verify: grep for key logging patterns returns 0 hits in production code. |
</threat_model>
