     ```rust
     use relm4::RelmApp;
     fn main() {
         let app = RelmApp::new("com.revelry.app");
         tracing_subscriber::fmt()
             .with_env_filter("revelry=debug")
             .init();
         app.run::<AppModel>(());
     }
     ```
     Use "com.revelry.app" as the application ID (standard GNOME reverse-DNS convention).

  2. Create src/app.rs with the root AppModel component:
     - Define ActiveView enum: Chat, Characters, Settings
     - Define AppMsg enum: SwitchView(ActiveView), ToggleSidebar, DbResult(DbOutput), Quit
     - Define AppModel struct with #[tracker::track]:
       - active_view: ActiveView
       - sidebar_visible: bool (default true)
       - has_providers: bool (default false, updated from DB)
       - db_worker: WorkerController<DbService>
       - chat_panel: Controller<ChatPanel>
       - characters_panel: Controller<CharactersPanel>
       - settings_panel: Controller<SettingsPanel>
       - tracker: u32 (required by tracker macro)
     - Implement SimpleComponent for AppModel:
       - type Init = ()
       - type Input = AppMsg
       - type Output = ()
       - type CommandOutput = ()
       - type Root = adw::ApplicationWindow

  3. Implement the view! macro for AppModel following the UI-SPEC.md Widget Hierarchy:
     - AdwApplicationWindow (1024x768 default)
       - AdwToastOverlay
         - AdwOverlaySplitView (sidebar_width_fraction=0.30, min=280, max=360)
           - sidebar: AdwToolbarView with AdwHeaderBar + GtkListBox (.navigation-sidebar) for conversation list
           - content: AdwToolbarView with AdwHeaderBar containing AdwViewSwitcher
             - GtkStack with three children: chat, characters, settings
     - AdwBreakpoint at 720px: add_setter collapsed=true on split_view
     - Keyboard shortcuts via gtk::ShortcutController:
       - F9 -> ToggleSidebar
       - Ctrl+1/Ctrl+2/Ctrl+3 -> SwitchView (Chat/Characters/Settings)
       - Ctrl+Comma -> SwitchView(Settings)
       - Ctrl+Q -> Quit
       - Escape -> close any open dialog
     For macOS: use cfg!(target_os = "macos") to swap Ctrl for Cmd in shortcut triggers.

  4. Implement init() for AppModel:
     - Initialize DbService Worker with database path from dirs::data_dir().join("revelry/revelry.db")
     - Create parent directories if they don't exist
     - Launch child panel components
     - Forward DbOutput from Worker to AppMsg::DbResult
     - Send DbInput::LoadProviders on init to check if first launch
     - Set initial active_view to Settings if no providers, Chat otherwise (per D-04 and D-12)

  5. Implement update() for AppModel:
     - AppMsg::SwitchView(view) -> set model.active_view, self.set_active_view(view)
     - AppMsg::ToggleSidebar -> toggle model.sidebar_visible, self.set_sidebar_visible(!self.sidebar_visible)
     - AppMsg::DbResult(output) -> forward to appropriate child, update has_providers
     - AppMsg::Quit -> close window

  6. Create src/ui/mod.rs declaring all UI submodules.
