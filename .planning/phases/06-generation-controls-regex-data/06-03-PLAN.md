<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backup file → DB | Imported SQL/ZIP is untrusted — could contain malicious SQL or corrupted data |
| File system → App | Export paths and import paths from file chooser are user-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-07 | Tampering | import_sql_dump | mitigate | SQL dump is app-generated format; migrations validate schema. Cannot downgrade from newer version. |
| T-06-08 | Denial of Service | import_zip_archive | accept | ZIP extraction could be large but is user-initiated and expected. No unbounded decompression (zip crate handles bomb detection). |
| T-06-09 | Tampering | export file path | accept | File path from GtkFileChooserNative is user-controlled; no privilege escalation possible (app writes as current user) |
| T-06-10 | Information Disclosure | SQL dump contents | accept | SQL dump contains all app data (expected behavior). User controls where file is saved. No secrets in DB (API keys in keyring). |
</threat_model>
