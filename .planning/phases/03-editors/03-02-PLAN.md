This is a single-form dialog (not a wizard). Key design:
- Props: `open: boolean`, `onOpenChange: (open: boolean) => void`, `mode: 'create' | 'edit'`, `persona?: UserPersona`
- State: `formData: Partial<UserPersona>`, `errors: Record<string, string>`, `isSaving: boolean`, `backendError: string | null`

- Avatar: `AvatarUpload` with `onUpload` calling `app.uploadAvatar()` then setting `formData.avatar_path`
- Name: `Input` with label "Name", validation: non-empty → error "Name is required."
- Appearance: `Textarea` with label "Appearance"
- Personality: `Textarea` with label "Personality"
- Background: `Textarea` with label "Background"
- Role description: `Input` with label "Role description"
- Relationships: `Textarea` with label "Relationships"
- Speech style: `Textarea` with label "Speech style"
- Tags: `Input` with label "Tags" (comma-separated, parsed to array on save)

Validation:
- Only `name` is required (per CONTEXT D-09)
- On save: validate name non-empty, if pass calls `app.createPersona(formData)` or `app.updatePersona(persona.id, formData)`
- When `isSaving` is true: disable all form fields, button shows "Saving…" with `Loader2` icon

Backend error banner: same pattern as CharacterEditorDialog — destructive styling at top of dialog body.

Dirty form guard: same pattern — track changes, show "Discard changes?" on close if dirty.

On `mode === 'edit'`, pre-populate all fields from `persona` prop. On `mode === 'create'`, all fields empty.

KebabMenu items use `DropdownMenu.Item` from bits-ui:
```svelte

  <DropdownMenu.Item class="flex items-center gap-2 rounded-sm px-2 py-1.5 text-sm text-(--color-foreground) hover:bg-(--color-surface-hover) cursor-pointer select-none" onclick={() => onedit?.(persona.id)}>
    Edit
  </DropdownMenu.Item>
  <DropdownMenu.Item class="flex items-center gap-2 rounded-sm px-2 py-1.5 text-sm text-(--color-destructive) hover:bg-(--color-destructive)/10 cursor-pointer select-none" onclick={() => ondelete?.(persona.id)}>
    Delete
  </DropdownMenu.Item>
```

Need to import `DropdownMenu` from `bits-ui` and `KebabMenu` from `$lib/components/ui`.

2. Modify `src/routes/characters/+page.svelte`:
   - Import `PersonaEditorDialog` from `$lib/components/personas`
   - Add persona editor dialog state:
     ```typescript
     let personaEditorOpen = $state(false);
     let personaEditorMode = $state<'create' | 'edit'>('create');
     let editingPersonaId = $state<string | null>(null);
     ```
   - Wire "New persona" button (in the header, visible when `tab === 'personas'`): `onclick={() => { personaEditorMode = 'create'; editingPersonaId = null; personaEditorOpen = true; }}`
   - Pass `onedit`, `ondelete` callbacks to PersonaCard:
     ```svelte
     <PersonaCard
       {persona}
       onedit={(id) => { personaEditorMode = 'edit'; editingPersonaId = id; personaEditorOpen = true; }}
       ondelete={(id) => { deletingEntity = { type: 'persona', id, name: persona.name }; deleteDialogOpen = true; }}
     />
     ```
   - Add `PersonaEditorDialog` component to the template:
     ```svelte
     <PersonaEditorDialog
       open={personaEditorOpen}
       onOpenChange={(v) => { personaEditorOpen = v; }}
       mode={personaEditorMode}
       persona={personaEditorMode === 'edit' && editingPersonaId ? app.personas.find(p => p.id === editingPersonaId) : undefined}
     />
     ```
   - Extend the existing `DeleteConfirmationDialog` `onConfirm` handler to also handle persona deletion:
     ```typescript
     onConfirm={async () => {
       if (deletingEntity.type === 'character') await app.deleteCharacter(deletingEntity.id);
       else if (deletingEntity.type === 'persona') await app.deletePersona(deletingEntity.id);
       deleteDialogOpen = false;
       deletingEntity = null;
     }}
     ```
</action>
